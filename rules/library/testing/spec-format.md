# 测试规格格式规则

阶段输入的 `testSpecTemplatePath` 是唯一模板来源，必须保留其 8 个一级章节和测试用例下的 12 类场景标题。

- 每个适用用例包含稳定的用例 ID、场景、前置条件、输入和可验证的预期结果。
- 预期结果使用 `EX1`、`EX2` 等编号；Mock 与配置使用 `M1` 等编号，并在测试数据或 Mock 清单中回指。
- 覆盖率意图清单要将变更方法与测试入口、用例 ID 对应起来。
- 对不适用的场景写 `N/A：本需求暂无此类场景`，不能删除标题或为了填满章节虚构用例。
- 环境章节使用 Java/JUnit5 + Mockito 的 mock-first 口径；HTTP 测试使用 standalone MockMvc，除非技术方案明确要求其他方式。
