# Java 集成与分布式规范

适用于 Redis、消息队列、OpenFeign、Elasticsearch 或分布式任务改动。

- 缓存 Key 使用稳定、可定位的命名空间并设置合理 TTL；更新数据后遵循项目既有缓存失效顺序。
- 分布式锁复用项目现有实现；释放锁必须在 `finally` 中执行，禁止自行拼装不可靠的锁协议。
- 消息消费必须具有幂等语义；数据库写入与发消息使用项目认可的事务消息或本地消息表模式。
- 远程调用显式配置超时；非幂等操作不得盲目自动重试。
- 搜索、批处理和分布式任务必须设置范围、分页或限流，避免无条件全量查询和不可控重试。
- 具体组件、客户端和配置名称以项目现有实现为准，不得把本规则中的示例当作新依赖的授权。
