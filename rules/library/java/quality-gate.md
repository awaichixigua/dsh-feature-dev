# Java 代码质量门禁

适用于 Java 实现完成后的自检，以及 Java diff 的 Code Review。

## 审查范围

- 只检查本次 diff 新增或修改的代码；可读取邻近上下文以理解变更。
- 不对同文件未改动的历史代码提出本阶段 BLOCK 或 WARN；历史问题单独记录为技术债。

## BLOCKER 检查

对本次变更确认不存在以下问题：

1. `SELECT *` 或 MyBatis `${}` SQL 拼接。
2. 手动创建线程、未使用项目线程池，或异步任务未指定执行器。
3. 非 Service 公共入口的事务、事务中的 RPC/HTTP 调用，或明显失效的事务代理边界。
4. 硬编码密码、密钥、令牌、内网地址或敏感信息日志。
5. 空 `catch`、吞掉异常、`finally` 返回值。
6. Controller 承载业务逻辑、DAO/Mapper 承载业务判断。
7. 缓存 Key 无 TTL、不可安全释放的分布式锁，或消息消费明显不幂等。
8. 新增代码违反项目既有的命名、响应体、模块边界或测试约定。

发现问题时，报告具体文件、行或可定位的代码位置，并说明与本次变更的关系。实现 Agent 应修复自己引入的问题；Review Agent 不直接扩大到无关重构。
