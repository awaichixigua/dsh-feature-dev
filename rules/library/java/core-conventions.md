# Java 核心编码规范

适用于 Java / Spring Boot 的新增和修改代码。

## 命名与对象模型

- 类名使用 `UpperCamelCase`，方法、变量和参数使用 `lowerCamelCase`，常量使用 `UPPER_SNAKE_CASE`。
- 禁止拼音与英文混用；禁止无语义缩写。
- DTO、VO、DO 等后缀只在项目既有约定中使用；不得为了套规则新建无用模型层。
- 布尔属性避免 `is` 前缀，防止序列化框架产生歧义。
- 避免魔法值；有限值域使用语义明确的常量或枚举。
- 包装类型比较值使用 `equals`；可空值在解包、远程返回和数据库返回处显式处理。

## 控制流、异常与日志

- 所有分支和循环使用大括号；复杂条件拆成有意义的布尔变量。
- 禁止空 `catch`、用异常做正常流程控制、在 `finally` 中 `return`。
- 异常必须保留业务语义和根因；用户侧返回项目统一错误结构，服务端日志记录必要上下文。
- 使用项目既有的日志门面与参数化日志；异常日志包含现场参数和异常对象，禁止记录密钥或敏感个人信息。
- 禁止 `System.out.println`、字段注入和硬编码密钥。

## 并发与可维护性

- 禁止手写 `new Thread()` 或无边界的默认线程池；复用项目已有线程池配置。
- 避免在循环中创建昂贵对象、建立连接或执行远程调用。
- 单个方法、条件嵌套和循环嵌套应保持可读；超过项目既有阈值时拆分职责而非复制代码。
